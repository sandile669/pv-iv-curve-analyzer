# PV IV Curve Analyzer v1.9
Run `py -m pip install -r requirements.txt` and `py -m streamlit run app.py` locally. On Streamlit Cloud use app.py as the entry point. Upload all source files and the templates folder, preserving names and paths. Select 15, 18 or 21 expected strings; the corresponding template is selected even if strings are cut or missing. Enter 0 for no cut strings. Upload the individual curves and the Raw Data Files summary. Word only; no LibreOffice required. Verify generated reports before acceptance.
